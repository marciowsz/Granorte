# Visão Granorte

Sistema inteligente de controle logístico utilizando Inteligência Artificial e Visão Computacional.

## Funcionalidades

- Detecção automática de caminhões
- Simulação de leitura de placas
- Controle de entrada e saída
- Verificação de carga
- Simulação de fraude na pesagem
- Interface web com Flask

## Tecnologias

- Python
- Flask
- YOLOv8
- OpenCV
- HTML/CSS
- Render
- GitHub

## Objetivo

Projeto acadêmico ainda em desenvolvimento como proposta de solução tecnológica para problemas logísticos em operações de pedreira e transporte de cargas.
